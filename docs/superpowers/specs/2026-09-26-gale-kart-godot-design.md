## 1. 目标与成功标准

在 Godot 4.7 中做一个 3D 卡丁车竞速游戏，玩法对标跑跑卡丁车，内容与完成度全面超过网页版参考项目（下称"参考版"），画面适合录制分享视频。

成功标准：

1. **手感**：移植参考版已验证的街机物理，并加入渲染插值、尾流、更好的相机与车身动态、手柄震动；漂移、小喷、氮气、起步加速、跳台、加速带的反馈明显。
2. **内容**：4 种模式（竞速赛 / 道具赛 / 计时赛 / 大奖赛）、6 条赛道、5 款赛车 × 12 名车手 × 5 种涂装、10 种道具、7 名 AI（3 档难度）、1 / 3 / 5 圈。
3. **完整流程**：标题 → 主菜单 → 赛前设置（3D 车库预览）→ 加载 → 开场航拍 → 倒计时 → 比赛 → 冲线 → 颁奖台 → 结算 → 精彩回放 / 再来一局 / 下一赛道 / 返回；暂停、设置、操作说明、最佳纪录。
4. **视频友好**：精彩回放（电视转播机位、自动切镜、可换焦点车、变速、暂停）；比赛中可一键隐藏 HUD。
5. **声音**：全部音效和 8 首 BGM 离线合成（Python），引擎声随转速变化，AI 车有 3D 定位引擎声。
6. **性能**：在这台 Mac（RX 5500 XT）上，1080p「高」画质稳定 60 帧。
7. **测试**：无界面整场 AI 比赛（6 条赛道 × 8 车 × 3 圈全部完赛、无人卡死）、赛道几何校验、道具逻辑、操控数据；每个界面和赛道都截图检查。

## 2. 技术选型

| 决策 | 选择 | 理由 |
|---|---|---|
| 引擎 | Godot 4.7.2，GDScript（全静态类型） | 已安装；GDScript 迭代快 |
| 渲染 | Forward+（Vulkan/MoltenVK） | 已验证可用；阴影、SSAO、辉光、体积雾 |
| 物理 | 移植参考版的自研街机物理（不使用物理引擎） | 用户认可它的手感；可精细调参；可在无界面模式下快速仿真 |
| 模型 | Kenney CC0 模型：Car Kit（5 款卡丁车）、Mini Characters（12 名车手，自带 drive 动画）、Racing Kit / Nature Kit / City Kit（场景物件） | 免费可商用、不用署名，低多边形风格统一 |
| 赛道、地形、特效 | 代码生成网格 + 自写着色器 | 赛道形状自由，AI 路线和检查点也来自同一条曲线 |
| 音频 | Python + numpy 离线合成 → ffmpeg 转 OGG | 零版权风险，音色可控 |
| 字体 | ZCOOL KuaiLe（标题/中文）、Bungee（数字），均为 OFL | 糖果风卡通 UI |
| 存档 | `user://save.json` | 设置、选择、纪录、幽灵车、大奖赛最佳 |
| 测试 | `godot --headless -s tests/run_tests.gd` | 仿真层与渲染层分离，可以快速跑整场比赛 |

## 3. 架构

仿真与表现严格分离：`src/sim/*` 只用 `RefCounted` 和数学类型，不创建节点，可以在无界面模式下运行。

```
kart-racer/
  project.godot  README.md
  assets/
    models/{karts,characters,racing,nature,city}/   Kenney GLB（各自带 Textures/colormap.png）
    audio/{sfx,music}/                               离线合成的 OGG
    fonts/                                           ZCOOLKuaiLe、Bungee
    shaders/                                         路面、地形、积雪、水面、道具箱、速度线、径向模糊等
  src/
    autoload/   game.gd（全局流程/切场景）store.gd（存档）audio_manager.gd（音频）
    data/       karts.gd tracks.gd items.gd themes.gd   纯数据
    sim/        mathx.gd track_data.gd terrain_data.gd kart_sim.gd ai_driver.gd
                item_system.gd race_sim.gd replay_recorder.gd
    view/       race_world.gd（组装一场比赛的 3D 世界）track_mesh.gd terrain_mesh.gd
                scenery.gd environment_factory.gd kart_view.gd kart_model.gd item_view.gd
                effects.gd skid_marks.gd camera_rig.gd tv_cameras.gd ghost_view.gd
    race/       race_controller.gd（sim + view + HUD + 音频 的胶水；事件分发）
                replay_player.gd
    ui/         hud/*  menus/*  theme/*
  scenes/       main.tscn（入口）race.tscn menu.tscn
  tests/        run_tests.gd + 各测试套件；tools/（整场仿真、操控数据、截图脚本）
  tools/        gen_audio.py
```

数据流：`输入 → RaceSim.update(dt)（固定子步 1/120 s）→ events[] → 表现层、音频、HUD 消费`。表现层按子步余量在上一状态和当前状态之间插值，高刷新率下也平滑。

## 4. 坐标与单位

- Y 轴向上，单位米。车头朝向 θ：forward = (sinθ, 0, cosθ)，right = (−cosθ, 0, sinθ)，θ 增大为左转（与参考版一致）。
- Godot 节点 `rotation.y = θ`；Kenney 模型朝 +Z，可以直接对齐。
- 显示时速 = m/s × 3.6 × 1.4（街机式夸张读数）。

## 5. 赛道

沿用参考版的赛道算法：闭合 centripetal Catmull-Rom 样条，按约 2 m 弧长均匀采样；横向依次是路面半宽 W → 路肩（减速区）→ 护墙；投影查询、赛车线（弹性带平滑）、跳台楔形高度、加速带、道具箱排、发车格。

## 6. 赛车物理（街机）

完整移植参考版 `kart.js`：前向/侧向速度分解、侧向抓地指数衰减并部分转为前向、低速转向衰减、漂移状态机、集气、瞬间加速窗口、起步加速、护墙反弹、车车冲量碰撞、竖直弹道（g = 25）、加速带、各种受击状态、逆行检测、复位。

在此之上改进：

1. **渲染插值**：120 Hz 物理，渲染取上一子步与当前子步的插值。
2. **尾流**：紧跟前车（前方 3–14 m、横向偏差 < 2.2 m）累计 1.0 s 后获得 1.2 s、+12% 的尾流加速，出现风线特效。
3. **小喷提示**：漂移满 0.35 s 后火花由白变蓝；松开漂移后的小喷窗口里，HUD 出现「↑」提示并播放提示音；成功时出现蓝色尾焰和「瞬间加速！」字样。
4. **车身动态**：侧倾、俯仰、落地压缩回弹、前轮转向、轮子按速度转动、漂移时车身甩角、车手身体随转向倾斜。
5. **相机**：弹簧跟随；漂移时航向滞后，把车身角度露出来；速度越快 FOV 越大，加速时再放大，并叠加速度线和径向模糊；落地和碰撞时镜头震动；开场航拍，冲线后环绕。
6. **手柄**：左摇杆转向曲线（死区 0.12、指数 1.4）、扳机油门刹车；受击、落地、放氮气时手柄震动。

5 款赛车（1–5 星，参数公式沿用参考版 `kartParams`）：

| 车 | 极速 | 加速 | 操控 | 漂移 | 氮气 | 重量 | 外观差异 |
|---|---|---|---|---|---|---|---|
| 棉花糖 | 3 | 3 | 3 | 3 | 3 | 3 | 标准车身 |
| 闪电 | 5 | 2 | 2 | 3 | 3 | 3 | 大尾翼、赛车轮 |
| 旋风 | 3 | 4 | 5 | 4 | 2 | 2 | 小尾翼、车身缩小 5% |
| 火箭 | 4 | 3 | 2 | 2 | 5 | 3 | 双排气火箭筒 |
| 铁甲 | 3 | 2 | 3 | 3 | 3 | 5 | 前保险杠、宽胎、车身放大 6% |

涂装 5 种，对应 Kenney 卡丁车的 5 个配色版本（oobi 紫、oodi 粉、ooli 黄、oopi 青、oozi 米）。车手 12 名，对应 Mini Characters 的 male/female a–f，各配一个中文名，统一使用 `drive` 动画。

## 7. 模式

- **竞速赛**：漂移集气，满格得 1 个氮气（最多存 2 个），空格释放。
- **道具赛**：道具箱成排分布；2 个道具槽，Q 交换；按名次加权发放；不集气，但漂移仍可小喷。
- **计时赛**：单人；保存最佳一局的幽灵车（10 Hz 采样）；显示与最佳纪录的实时差距。
- **大奖赛**：两个杯赛，每杯 3 条赛道（新星杯：小镇、沙漠、冰雪；疾风杯：森林、赛车场、夜城）；规则可选竞速或道具；积分 10/8/6/5/4/3/2/1；每场后显示积分榜，杯赛结束颁奖。

## 9. AI

沿用参考版：沿赛车线前视跟随、个体车道偏置、按前方曲率规划速度、视觉漂移与集气、直道放氮气、避让车辆和危险物、道具策略、卡住自动复位、失误摆动；三档难度影响极速系数、走线精度、道具积极性、橡皮筋强度、起步加速概率。另外加入：AI 也会利用尾流；困难档 AI 会在出弯时小喷。

## 10. 表现

- 环境：每个主题有独立的天空（ProceduralSky 调色或渐变着色器）、雾、太阳光、阴影；AgX/ACES 色调映射，辉光，SSAO；夜城加体积雾和点光源路灯；冰雪有飘雪粒子并给树木覆盖积雪（按法线朝上混入白色的着色器）。
- 粒子：漂移烟、漂移火花（白→蓝）、氮气尾焰（蓝白）、加速带尾焰（橙）、尾流风线、越野尘土、撞墙火花、落地尘、车车碰撞星星、道具箱碎片、爆炸、水花、香蕉、护盾、复位光柱、终点彩带、飘雪；漂移胎痕用环形缓冲网格。
- 屏幕效果：速度线（屏幕空间着色器）、氮气径向模糊、乌云遮挡、导弹锁定时屏幕边缘泛红。
- 车手名牌（Label3D），计时赛幽灵车用半透明材质。

## 11. UI

视觉沿用参考版的糖果贴纸风：深墨蓝描边 #1B1F3B、阳光黄 #FFC93C、泡泡蓝 #3EC6FF、赛车红 #FF4D5E、薄荷绿 #45E3A6、云白 #F7FAFF；圆角、粗描边、投影。全部中文。

- 标题页：3D 背景（车库转台上的赛车），Logo，「按任意键开始」。
- 主菜单：快速比赛、大奖赛、计时赛、最佳纪录、设置、操作说明、退出。
- 赛前设置：模式、赛道（缩略图 + 难度星级 + 最佳纪录）、车手、赛车（六维属性条）、涂装、难度、圈数；右侧 3D 车库实时预览。
- HUD：名次（大号）、圈数、总时间 / 单圈 / 最佳、速度表（弧形）、集气条 + 氮气槽或道具槽（含轮盘动画）、小地图、实时排名、中央提示（倒计时、GO、最后一圈、FINISH、小喷、道具提示）、逆行警告、导弹锁定警告、计时赛与幽灵车的差距。按 H 隐藏 HUD。

## 12. 精彩回放

- 比赛中以 30 Hz 记录每辆车的位置、朝向、速度、漂移角、转向、状态标志，道具实体的位置，以及离散事件（爆炸、水花、道具箱、落地、撞墙等）。
- 回放时由记录数据驱动车辆和道具的表现，按事件触发特效和音效。
- 机位：电视转播（沿赛道自动布置，选离焦点车最近且视线通畅的机位，自动切换）、追尾、环绕、俯瞰；按 1–4 切换，←→ 换焦点车，空格暂停，[ ] 变速（0.25× / 0.5× / 1× / 2×），H 隐藏界面，Esc 退出。

## 13. 音频

- 音效（约 40 个）：引擎循环、漂移摩擦、集气满、氮气、小喷、起步加速、加速带、撞墙、碰车、落地、倒计时、GO、圈数、最后一圈、完赛、胜利 / 失败 / 新纪录、道具轮盘、获得道具、导弹发射 / 锁定 / 爆炸、水炸弹、水泡、香蕉、打转、护盾、乌云、雷暴、磁铁、飞碟、水苍蝇、复位、逆行、菜单点击 / 悬停 / 返回 / 确认。
- BGM（8 首）：菜单、6 条赛道各一首、结算；芯片风加合成器贝斯，循环无缝；最后一圈 BGM 提速 10%。
- 总线：Master / Music / SFX，设置里可调；比赛中暂停时降低音乐音量并暂停音效。

## 14. 测试与验收

1. `tests/test_track.gd`：每条赛道闭合、最小转弯半径 ≥ 护墙偏移 + 余量、非相邻路段间距足够（立交高度差 ≥ 6 m 例外）、发车格和道具箱都在路面内、跳台和加速带不重叠。
2. `tests/test_race.gd`：每条赛道 8 辆 AI 跑 3 圈（无界面加速仿真），全部完赛、无人卡死、单圈时间在合理区间；玩家输入脚本冒烟测试（直线加速、漂移集气、氮气、小喷、起步加速、尾流）。
3. `tests/test_items.gd`：道具权重合法；拾取、命中、护盾、各道具效果。
4. `tests/test_replay.gd`：记录和回放的帧数一致、插值正确。
5. 截图验收：每条赛道的开场、比赛中、夜景，各个菜单页面、HUD、结算、回放。
6. 性能：记录「高」画质下每条赛道的平均帧率和最低帧率。
